# Audio (original procedural)

All WAVs generated for DriveViceCity (not ripped):

- `engine_idle.wav` / `engine_accel.wav` — layered loops
- `engine_loop.wav` — legacy single loop (optional)
- `horn.wav` — dual-tone horn (press **H**)
- `tire_screech.wav` — slip / handbrake one-shot
- `collision_thud.wav` — impact feedback
- `city_ambience.wav` — low-volume loop

Wired via `scripts/vehicle_audio.gd`. Toggle with `GameSettings.audio_enabled`.
