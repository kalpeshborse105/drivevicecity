# 05 — Roadmap

Ship small, playable slices. **Do not expand the map until the current slice is fun.**

| Phase | Goal | Deliverable | Exit criteria |
|-------|------|-------------|---------------|
| **P0** | Free drive | Placeholder Dhule block + 1 car | 10 min drive feels OK on PC |
| **P1** | Vertical slice | Real OSM clip **or** polished block + **1 delivery mission** | 10 deliveries without soft-lock |
| **P2** | Soft launch | Full Dhule playable area, 3 vehicles, paint, 3 job types | Closed test on Play Console |
| **P3** | Store 1.0 | Economy, garage, more jobs, polish | Public free release |
| **P4** | Expand | Neighbor towns / India hub select (not full country mesh) | Only after retention looks good |
