# 07 — Play Store (when we publish)

You already have a **Play Console organization account**. That covers the paid developer seat. Still needed later:

## Account / policy

- [ ] Org identity verified (D-U-N-S / India docs if Google asks)
- [ ] Live **privacy policy** URL (GitHub Pages is free)
- [ ] Data safety form + content rating questionnaire
- [ ] Store listing: title, short/full description, icon, feature graphic, screenshots
- [ ] Contact email for the listing

## Build

- [ ] Godot Android export templates installed
- [ ] JDK + Android SDK / debug keystore for testing
- [ ] Release **.aab** (Android App Bundle) signed with Play App Signing
- [ ] Package name reserved (e.g. `com.yourorg.drivevicecity`) — choose once, keep forever

## Release track

1. Internal testing  
2. Closed testing (friends / testers)  
3. Open testing (optional)  
4. Production
